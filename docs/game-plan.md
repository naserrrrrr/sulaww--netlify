# خطة اللعب: «مهمة المجرّة» (مسودة للاعتماد)

## 1. الأصول ودورها في اللعبة

| العنصر في اللعبة | الأصل الرسمي | طريقة الاستخدام |
|---|---|---|
| صاروخ اللاعب | `lottie-rocket.json` (صاروخ عمودي يظهر ريان وبيان في نافذته، بلهب متحرك) | يُحوَّل عند البناء إلى Spritesheet (12 إطاراً) لأداء أعلى، وتُولَّد 4 ألوان للهيكل من لوحة الهوية |
| ريان | `rayan-pose-*`، و`avatar-rayan`، و`lottie-rayan-fly-*` | القصة، والخريطة، والنصر، وأفاتار الواجهة |
| بيان | `bayan-pose-*`، و`avatar-bayan`، و`lottie-bayan-fly-*` | صندوق الرسائل اللاسلكية، والقصة، والاحتفال |
| «خُردة» | `robot-yellow` (روبوت الهوية الطويل المقسّم) | زعيماً بحجم كبير، مع أعطال مرئية (شرر، ودخان، واهتزاز، وضوء تحذير). يعود لهيئته الطبيعية عند الإصلاح |
| الكواكب | `planet-mars`، و`planet-saturn`، وباقي الكواكب | الخريطة، وخلفيات Parallax |
| العملة والألماس | `icon-coin`، و`icon-diamond` | قطع الجمع والواجهة والمتجر |
| الهدية والصاروخ والسهم والإشعار | `icon-gift`، و`icon-rocket`، و`icon-arrow`، و`icon-notification` | صناديق القوى الخاصة، والحظيرة، ومؤشر الجاذبية، والإنذار |
| النجمة الذهبية المخفية | `lottie-star-1` | 3 نجوم مخفية في كل مرحلة |
| خلفية الفضاء | `space-bg-*`، و`star-6pt`، و`burst-*` | طبقات Parallax: لون عميق، ثم نجوم، ثم سحب، ثم كواكب بعيدة |
| النصر | `lottie-celebrate`، و`sticker-bayan-gifts` | شاشة الاحتفال |
| البداية | `lottie-logo-intro` + الشعار الأبيض | شاشة البداية |
| الخط | Montserrat Arabic (woff2 محلي) | كل النصوص والأرقام |

لا توجد بدائل مؤقتة: كل ما تحتاجه اللعبة متوفر رسمياً. النيازك والشظايا والطلقات وكتل الجليد والبوابات أشكال هندسية تُرسم برمجياً بألوان الهوية وزواياها الدائرية، فالدليل لا يتضمنها.

## 2. الشاشات

البداية (حركة الشعار) ← القائمة ← القصة (3 لوحات، قابلة للتخطي) ← الخريطة (المريخ ثم زحل) ← اللعب ← الإيقاف ← النتائج (النجوم والعملات) ← الحظيرة ← المرحلة 2 ← النصر ← النتيجة النهائية. ومن القائمة: الحظيرة، والإنجازات، والإعدادات.

## 3. المرحلتان (الخط الزمني)

**المرحلة 1: مطر نيازك المريخ (≈ 2:40)**

| الوقت | المحتوى | الكثافة |
|---|---|---|
| 0:00–0:40 | تعليم برسائل بيان، ونيازك صغيرة بطيئة، ومسارات عملات | 0.9 نيزك/ث، والسرعة 220–300 |
| 0:40–1:30 | نيازك أسرع، ونيازك كبيرة تنقسم، وأول القوى الخاصة، وعملات مغرية | 1.4/ث، والسرعة 300–420 |
| 1:30–2:10 | «عاصفة!»: إنذار، ونيازك قطرية، ومكافأة النجاة | 2.0/ث، والسرعة 380–480 |
| 2:10–2:40 | الزعيم: الصخرة العملاقة (3 شقوق، 25 نقطة صحة لكل شق) | حلقات من 12 شظية يسبقها إنذار 0.8ث |

**المرحلة 2: حلقات زحل (≈ 3:00)**

| الوقت | المحتوى |
|---|---|
| 0:00–1:00 | بوابات الحلقات (+1 للمضاعف واندفاعة)، وكتل جليد أفقية، وجاذبية 180px/ث² يتبدّل اتجاهها كل 6–9ث بإنذار 1.5ث |
| 1:00–1:50 | ممرات ضيقة، وبوابات متحركة، وتفرّع بين مسار آمن ومسار بمكافأة مضاعفة |
| 1:50–3:00 | «خُردة» بثلاث مراحل: شعاع مسح بإنذار 0.8ث ونواتان (30 لكل نواة)، ثم طائرات مخلفات وكرات ملاحِقة، ثم عند 30%: أسرع، مع نواة مكشوفة 1.2ث بعد كل هجوم |

## 4. أرقام التوازن الأولية (`config/balance.ts`)

| النظام | القيمة |
|---|---|
| حركة الصاروخ | سرعة قصوى 900px/ث، وتنعيم 0.25 (قصور خفيف)، وإزاحة فوق الإصبع 110px |
| صندوق الاصطدام | دائرة نصف قطرها 26px، أي نحو 55% من الصاروخ، لتكون الإصابة عادلة |
| الحصانة بعد الإصابة | 1.0ث بوميض 3 مرات/ث كحد أقصى |
| الليزر | 6 طلقات/ث، والضرر 1 ← 1.35 ← 1.7 حسب الترقية |
| الكومبو | كل 8 عمليات جمع أو تحطيم ترفع المضاعف درجة (حتى ×5)، ويُصفَّر عند الإصابة |
| النجاة | مسافة أقل من 30px من حافة النيزك تمنح +50 نقطة و+2 للسلسلة، مع تبطيء 80ms بنسبة 0.3 |
| القوى الخاصة | 8ث، وتظهر كل نحو 18–25ث من الموجة 2 |
| التوربو | كل عملة تشحن 4%، وعند الامتلاء اندفاع محصّن 1.5ث يحطّم ما يصطدم به |
| Hit-stop واهتزاز الشاشة | 50ms، واهتزاز 0.004 عند الإصابة و0.008 عند الزعيم |
| النجوم | ★ إنهاء المرحلة، ★★ تجاوز 12,000 (المريخ) أو 18,000 (زحل)، ★★★ جمع 3 نجوم مخفية |
| المساعدة الخفية | بعد خسارتين في المقطع نفسه تنخفض الكثافة 15% |
| الاقتصاد | جولة متوسطة: نحو 250 عملة في المريخ، ونحو 600 في الجولة الكاملة |
| الترقيات | 4 ترقيات بثلاثة مستويات: 120 ثم 300 ثم 500 (أي 3,680 للكل، ونحو 6 جولات كاملة) |
| ألوان الصاروخ | الأصلي مجاني، و3 ألوان بـ 200 لكل لون |

## 5. التقنية

Vite + TypeScript + Phaser 3.90 (Arcade). الدقة الأساسية 720×1280 مع `Scale.FIT`. طبقة DOM للنصوص العربية. `lottie-web` محلياً لشاشات البداية والقصة والنصر. Spritesheet للصاروخ يُولَّد عند البناء عبر `scripts/render-lottie.mjs`. `npm run build:single` يُخرج ملف `index.html` واحداً.
