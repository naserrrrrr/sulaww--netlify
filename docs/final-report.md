# التقرير النهائي: «مهمة المجرّة»

## ما بُني

- لعبة كاملة بمرحلتين وزعيمين، بهوية «ريان وبيان» الرسمية (الشعار، والشخصيات، والأيقونات، والكواكب، والخط Montserrat Arabic، وصاروخ Lottie الرسمي بأربعة ألوان).
- **المرحلة 1 «مطر نيازك المريخ»**: 3 موجات (تعليم داخل اللعب، ونيازك كبيرة تنقسم، وعاصفة بنيازك قطرية)، ثم «الصخرة العملاقة» بثلاثة شقوق وحلقات شظايا مُنذرة.
- **المرحلة 2 «حلقات زحل»**: جاذبية جانبية بمؤشر وإنذار قبل التبدّل، وبوابات (+1 للمضاعف)، وكتل جليد، وجدران حطام بفجوة واحدة، وتفرّع «يسار آمن / يمين مضاعف»، ثم «خُردة» بثلاث مراحل (شعاع مسح مُنذر، وتشكيلات مخلفات، وكرات ملاحِقة، ومخاطر الحواف) ويُصلَح في النهاية.
- الأنظمة: 3 قلوب، ونقطة حفظ قبل الزعيم، وعملات وألماس، وكومبو ×1–×5، و«نجاة!» بتبطيء 80ms، ودرع/مغناطيس/ليزر ثلاثي، وتوربو يُشحن من العملات، و3 نجوم لكل مرحلة، ومساعدة خفية بعد خسارتين، وHit-stop واهتزاز وجسيمات وأرقام طافية وخطوط سرعة.
- الحظيرة: 4 ترقيات بثلاثة مستويات و4 ألوان للصاروخ. 8 إنجازات. وضع التحدي (لا نهائي، أفضل 5 نتائج).
- الشاشات: البداية، والقائمة، والقصة (3 لوحات)، والخريطة، واللعب، والإيقاف، والنتائج، والحظيرة، والإنجازات، والإعدادات، والنصر. كلها DOM عربية RTL.
- الصوت: 15 مؤثراً مولّداً بـ Web Audio، بلا ملفات صوت ولا موسيقى. الكتم والمستوى محفوظان.
- الحفظ: `localStorage` بمفتاح `rb-galaxy-save-v1` داخل try/catch مع «إعادة ضبط».

## التشغيل والنشر

- الملف الجاهز للنشر: `galaxy/index.html` (ملف واحد يضم كل الأصول، 3.1MB). على Netlify يُفتح من `/galaxy/` دون أي إعداد.
- التطوير: `cd game && npm install && npm run dev`. التفاصيل في `game/README.md`.

## الاختبار الذي أُجري

- Playwright على Chromium بلا رأس (WebGL برمجي)، بمقاسي 390×844 و1440×900: القائمة، والقصة، والخريطة، والحظيرة، واللعب، والإيقاف والاستئناف، والإعدادات، والخسارة، ونقطة الحفظ، وهزيمة الزعيمين، وشاشة النصر، والنتائج، والإنجازات، وثبات الحفظ بعد إعادة التحميل.
- صفر أخطاء في Console في كل السيناريوهات (التحذيرات الوحيدة من WebGL البرمجي في المتصفح بلا رأس).
- قياس FPS غير ممكن بدقة في هذه البيئة (رسم برمجي بلا GPU)؛ راجع «القيود».

## القيود المعروفة

- لم يُقَس الأداء على جوال حقيقي. البناء خفيف (3.1MB) ويستخدم Object Pooling، لكن 60fps يحتاج تأكيداً على جهاز متوسط.
- الاهتزاز (`navigator.vibrate`) لا يعمل على iOS Safari (قيد المنصة).
- الأيقونات الصغيرة لبطاقات الترقيات رموز نصية لا أصول هوية، لأن الدليل لا يتضمن أيقونات لهذه المفاهيم.

## نصائح ضبط التوازن (`game/src/config/balance.ts`)

- صعوبة عامة: `marsWaves[].rate` و`speed`، و`saturnSections[].rate`.
- عدالة الإصابة: `player.hitRadius` (26px ≈ 55% من الصاروخ) و`player.invulnSeconds`.
- الزعماء: `bossRock.crackHp` و`ringIntervalSeconds`، و`bossRobot.coreHp` و`coreExposeSeconds`.
- الاقتصاد: `economy.upgradeCosts` و`skinCost`، ونسبة ظهور العملات في `spawnCoinPattern`.
- النجوم: `stars.marsScore` و`saturnScore`.
