# وكيل تحليل محفظة الأصول للقطاع غير الربحي (Claude Code)

يحلل الوكيل ملف Excel لسجل أصول أو عقارات أو أوقاف، ثم يسلّم أربعة مخرجات:

- **دراسة متعمقة:** فحص كل الأوراق بما فيها المخفية، وتنظيف البيانات، ومؤشرات بقواعد احتساب صارمة، وتشخيص للفجوات، وتوصيات.
- **داشبورد تفاعلي:** عربي باتجاه RTL، يعمل دون إنترنت، متجاوب مع الجوال وقابل للطباعة.
- **مرفق Excel داعم:** قابل للمراجعة.
- **خطة تنفيذ:** على 30 و60 و90 يومًا.

## طريقة الاستخدام في Claude Code

بعد التثبيت افتح Claude Code في المجلد الذي فيه ملف Excel، ثم استخدم إحدى الطريقتين:

| الطريقة | الأمر | متى تستخدمها |
|---|---|---|
| المهارة مباشرة (موصى بها) | `/asset-portfolio-analysis path/to/file.xlsx` | تريد متابعة التحليل والإجابة عن أسئلته أثناء العمل |
| الوكيل الفرعي | «استخدم الوكيل asset-portfolio-analyst لتحليل الملف path/to/file.xlsx» | تريد تشغيلًا كاملًا في سياق مستقل يعيد لك الخلاصة والأسئلة في النهاية |

لتحديث تحليل سابق بملف جديد، مرّر مجلد التشغيل السابق مع الملف:
`/asset-portfolio-analysis new.xlsx outputs/portfolio-analysis/<التشغيل_السابق>`

## المخرجات

تُكتب المخرجات في `outputs/portfolio-analysis/<اسم_الملف>_<التاريخ>/` داخل المجلد المفتوح، والملف الأصلي لا يُعدَّل:

| الملف | المحتوى |
|---|---|
| `dashboard.html` | الداشبورد: افتحه في أي متصفح، واطبع العرض التنفيذي منه |
| `supporting_workbook.xlsx` | الأصول، والحسابات، والمستبعدات، ومشكلات البيانات، والتوصيات، والخطة التشغيلية؛ والمطابقة مع الإجماليات، ومتابعة التوصيات، ومقارنة الإصدارات عند وجودها |
| `01…09_*.json/md` | سجل العمل الكامل: خريطة المصنف، والتصنيف، والسجلات، والمؤشرات، والسرد، والتحقق، واختبار المتصفح، ورسالة التسليم |
| `screens/` | لقطات اختبار المتصفح: سطح المكتب كاملًا ومقاطع بحجم الشاشة، وكل التفاصيل مفتوحة ومقاطعها، والجوال بعرضين ومع تفاصيل أصل، والطباعة PDF |
| `version_comparison.json` | عند تحديث تحليل سابق فقط: فروق النسختين مصنفة، ومتابعة التوصيات السابقة |

## التثبيت

**على مستوى المستخدم (موصى به):** شغّل `install.sh` من مجلد الحزمة `asset-portfolio-agent/`، لا من النسخة المثبتة:

```bash
cd asset-portfolio-agent
bash .claude/skills/asset-portfolio-analysis/install.sh
```

ينسخ الأمر المهارة إلى `~/.claude/skills/asset-portfolio-analysis` والوكيل إلى `~/.claude/agents/`، ويثبّت متطلبات Python. لإصدار أحدث أعد الأمر نفسه من مجلد الحزمة الجديدة؛ يستبدل النسخة المثبتة كاملة. أما تشغيل `install.sh` من النسخة المثبتة نفسها فلا يغيّر شيئًا، ويطبع تنبيهًا بذلك.

**داخل مشروع واحد:** انسخ مجلد `.claude` من الحزمة إلى جذر المشروع، ثم ثبّت المتطلبات:

```bash
python3 -m pip install -r .claude/skills/asset-portfolio-analysis/requirements.txt
```

إن رفض pip التثبيت (`externally-managed-environment`) فأنشئ بيئة افتراضية وفعّلها قبل فتح Claude Code، ثم أعد الأمر: `python3 -m venv .venv && . .venv/bin/activate`

**المتطلبات:**

- Python 3.10 أو أحدث، مع `openpyxl` و`jsonschema`، و`hijridate` اختياري للتواريخ الهجرية.
- لاختبار الداشبورد آليًا: Node.js 18 أو أحدث مع Playwright وChromium:
  ```bash
  npm i -g playwright && npx playwright install chromium
  ```
  على Linux دون مكتبات النظام التي يحتاجها المتصفح قد يلزم بدلًا من الأمر الثاني: `npx playwright install --with-deps chromium`.
  إن لم يتوفر ذلك يُبنى الداشبورد ويُذكر صراحة أنه لم يُختبر في متصفح.

## مبادئ التصميم

- **السكربتات تحسب، والنموذج يفسّر.** كل رقم في الداشبورد يأتي من محرك حسابي واحد، وتطابق نسختا Python وJavaScript منه آليًا.
- **المجهول لا يتحول إلى صفر.** ولا يُجمع أي رقم من ورقة لم يتحقق نطاقها.
- **العوائد تُحسب من مجاميع متطابقة،** وتُسمّى بدقة تبيّن أساسها ونطاقها.
- **لا بيانات شخصية في أي مخرج،** ولا نشر أو إرسال للبيانات. أنماط البيانات الشخصية في ملف واحد (`assets/pii_patterns.json`) تطبقه كل السكربتات وفحص المتصفح، ويُفحص المرفق الداعم بعد حفظه.
- **كل قاعدة في الموجّه الأصلي** (`references/00-original-brief.md`) لها موضع تطبيق موثّق في `references/traceability.md`.

## الاختبارات

للتحقق من التثبيت شغّل الاختبارات من أي مجلد:

```bash
bash ~/.claude/skills/asset-portfolio-analysis/tests/run_tests.sh
```

في التثبيت داخل مشروع استبدل `~/.claude` بمسار `.claude` في المشروع.

- تعمل على مصنف وهمي بالكامل يحاكي مشكلات البيانات الشائعة، ولا تحتاج بيانات حقيقية.
- تستغرق 8 إلى 10 دقائق تقريبًا، أغلبها فحص الداشبورد في المتصفح. مع `APA_SKIP_BROWSER=1` تستغرق أقل من دقيقة، ويظهر فحص المتصفح «متخطى».
- تنتهي بسطر `RESULT: PASS` عند نجاح كل الخطوات.
- مجلد البناء الافتراضي `tests/_build/` داخل مجلد المهارة. لإبقائه خارجها حدّد مجلدًا آخر:
  `APA_BUILD_DIR=/tmp/apa-build bash ~/.claude/skills/asset-portfolio-analysis/tests/run_tests.sh`

`bash ~/.claude/skills/asset-portfolio-analysis/tests/test_install.sh` يختبر `install.sh` نفسه في مجلد منزل مؤقت، في ثوانٍ. التفاصيل في `tests/README.md`.
